## 0. 정상 상태
$ curl -s -o /dev/null -w '%{http_code}\n' http://13.125.53.24/health
200

## 1. 장애 주입: SG 80 규칙 제거
$ aws ec2 revoke-security-group-ingress --group-id sg-06cc1b31e3ecde061 --protocol tcp --port 80 --cidr 0.0.0.0/0 --query Return
True

## 3. 검증 B: SG 인바운드 규칙
$ aws ec2 describe-security-groups --group-ids sg-06cc1b31e3ecde061 --query 'SecurityGroups[0].IpPermissions[].[IpProtocol,FromPort,IpRanges[0].CidrIp]' --output text

## 3. 비교: 포트는 열려 있고 프로세스가 없을 때 (같은 서버의 미사용 포트 8080을 22와 같은 방식으로 내 IP에만 임시 개방)
(8080/tcp ← 내 IP/32 임시 허용)
$ time curl -v -m 5 http://13.125.53.24:8080/

(8080 규칙 즉시 제거)

## 4. 조치: SG 80 규칙 복구
$ aws ec2 authorize-security-group-ingress --group-id sg-06cc1b31e3ecde061 --protocol tcp --port 80 --cidr 0.0.0.0/0
True
